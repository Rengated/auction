# Хендофф: Hermes Trade — автоаукцион (мобильное приложение + веб + админка)

## Обзор

Это пакет дизайн-референсов для платформы онлайн-аукциона автомобилей **Hermes Trade**. Платформа состоит из трёх связанных продуктов:

1. **Мобильное приложение** (покупатель) — каталог лотов, живые торги, ставки, профиль, продажа авто. Файл: `Автоаукцион - Дизайн.html`.
2. **Веб-версия** (покупатель, desktop) — тот же функционал в раскладке для широкого экрана. Файл: `Автоаукцион - Веб.html`.
3. **Админка** (менеджер салона) — управление лотами, торгами, сделками, пользователями и параметрами аукциона. Файл: `Автоаукцион - Админка.html`.

Покупатель делает ставки в реальном времени; у каждого лота есть **резерв** (минимальная цена продажи) и **шаг ставки**. После победы менеджер сопровождает сделку. Салон берёт комиссию **1.5%** от суммы выкупа.

## О файлах дизайна

Файлы в этом пакете — это **дизайн-референсы, созданные на HTML/React (через Babel в браузере)**. Это прототипы, демонстрирующие предполагаемый внешний вид и поведение, **а не продакшн-код для прямого копирования**.

Задача — **воссоздать эти дизайны в целевой кодовой базе** с её собственным окружением (React, Vue, Next.js, нативное приложение и т.д.), используя её установленные паттерны, компоненты и библиотеки. Если кодовой базы ещё нет — выбрать наиболее подходящий стек под проект (рекомендация ниже) и реализовать дизайны там.

Прототипы используют React 18 + Babel Standalone прямо в браузере и стоковые фото с Unsplash CDN — в продакшене так делать не нужно. Воспринимайте их как точную спецификацию UI: цвета, типографику, отступы, состояния и поведение.

### Рекомендация по стеку (если кодовой базы нет)
- **Веб + админка:** React + TypeScript (Next.js или Vite). Стили — CSS-переменные/Tailwind. Темизация через `data-theme`.
- **Мобильное приложение:** React Native / Expo, либо адаптивный веб (PWA). Прототип сделан как мобильный экран 392×832.
- **Реальное время** (ставки, таймеры, лента торгов): WebSocket / SSE.

## Уровень готовности (Fidelity)

**High-fidelity (hi-fi).** Все три продукта — пиксель-перфектные макеты с финальными цветами, типографикой, отступами, состояниями и анимациями. Разработчик должен воссоздать UI один-в-один, используя дизайн-токены ниже и существующие библиотеки кодовой базы.

> В проекте также есть wireframe-файлы (`wf-*.jsx`, `wireframe.css`) — это ранние low-fi исследования. Они **не входят** в этот хендофф и не являются источником истины. Источник истины — три HTML-файла, перечисленные выше.

## Бренд

**Hermes Trade** — премиальный «аукционный дом» для авто. Тон: сдержанный, галерейный, люксовый. Не «маркетплейс», а «концурс».

- **Вордмарк:** «HERMES» шрифтом Marcellus (serif), трекинг `0.18em`, uppercase; под ним «TRADE» шрифтом Hanken Grotesk, трекинг `0.42em`, uppercase, меньшего кегля и приглушённого цвета.
- **Знак (H-mark):** окружность с двумя вертикальными штангами буквы «H» и диагональной перекладиной — стилизованная «H» / крылья Гермеса. См. компоненты `HermesH`, `HermesMark`, `HermesLogo` в `hifi-shared.jsx` и финальный логотип в `Hermes Trade - Логотип финал.html`.
- В веб-топбаре вордмарк рисуется как `HERMES` с акцентной частью (`.brand b { color: var(--accent) }`).
- В админке знак — тёмный квадрат-скругление с белой монограммой + «HERMES / TRADE».

### Бейджи статуса
Статусы лота (`STATUS` в `hifi-shared.jsx`):
| key | label | tone | группа |
|---|---|---|---|
| `live` | «В эфире» | live | live |

### Карточка лота (`LotCardBody`, общая для мобайла и веба)
Структура сверху вниз:
1. **Фото** (`Photo`, высота 182): бейдж статуса (top-left) + кнопка-закладка (top-right, акцент если в избранном), подпись «N фото».
2. Строка: `Марка Модель` (`700 17px`) + год (`--num 12px`, справа).
3. Мета через `·`: `пробег км · двигатель · топливо` (`--num 12.5px --text-dim`).
4. Разделитель `--line-soft`.
5. Низ: слева цена (`eyebrow` лейбл + `--num 20px 700`; цена продажи зелёным `--win`) и строка резерва (`резерв N ₽ · взят/не взят`); справа таймер (eyebrow «до конца»/«старт»/«завершён» + значение, срочное `--live`) и «N ставок».
6. Пунктирный футер: `старт <дата> · оконч. <дата>`.

`cardPriceMeta(lot, now)` определяет лейблы/значения по статусу. Для `live`/`ending` показывается «макс. ставка» + обратный отсчёт (`fmtTime`); `urgent` при ≤ 300 c.

### Фото-плейсхолдеры
`.photo` — диагональный градиент со штриховкой (`repeating-linear-gradient`), глиф-подпись (`--num`, напр. марка), опц. подпись `.cap` (счётчик «1 / 18»). В прототипе поверх кладётся реальное фото с Unsplash (`<img>`) с фолбэком на плейсхолдер при ошибке. **В продакшене** — это слот под реальные фото авто.

### Карусель (`Carousel`)
Стрелки `‹ ›` (круглые, blur-фон), точки-индикаторы (активная — акцентная «капсула» 16px). Свайп между кадрами.

### Лента ставок (`BidList`)
Строки: аватар-кружок (инициал; «Я» с акцентным фоном для своих), имя (своё — `700` акцентом), относительное время, сумма (`--num 15px`). При отсутствии ставок — «Ставок пока нет — будьте первым».

### Ввод ставки (`BidInput` / `.bid-input`)
Степпер: кнопка `−` (44px, веб 50px) | центральное поле (число `--num 700 19px` + подпись-хинт «ваша ставка, ₽») | кнопка `+`. Шаг = `lot.bid + шаг_ставки` (мин. след. ставка). Ввод только цифр.

## Экраны и вью

### A. Мобильное приложение (`Автоаукцион - Дизайн.html`)
Корневой компонент `App`: рамка телефона (392×832), нижняя навигация из 3 табов (`Лоты / Ставки / Профиль`), стек детальных экранов поверх. Таймеры тикают раз в секунду (`now`).

Аутентификация (`AuthFlow`, `hifi-auth.jsx`): экраны `welcome → phone → otp` (ввод телефона, 4-значный OTP). Состояние «вошёл» хранится в `localStorage` (`cc_authed`). Для участия нужны заполненные контакты (событие `cc-need-contacts` → экран «Личные данные»).

1. **Каталог** (`ScreenCatalog`) — eyebrow + заголовок, поиск, фильтры-чипы (`Все / В эфире / Скоро старт / Завершён / Избранное`), тикер живых ставок, список карточек лотов.
2. **Лот** (`ScreenLot`) — карусель фото, шапка (марка/модель/год, цена, таймер), табы `Обзор / Характеристики / Описание`, плитки характеристик, опции, отчёт Автотеки, лента ставок; липкий нижний бар со ставкой.
3. **Живые торги** (`ScreenLiveLobby`) — лобби лотов «в эфире», отсортированных по времени до конца; live-пилюля со счётчиком.
4. **Живой лот** (`ScreenLive`, `hifi-live.jsx`) — режим активных торгов с крупным таймером и живой лентой.
5. **Мои ставки** (`ScreenMyBids`) — табы `Активные / Выигранные / Избранное`; строки с тегами статуса (лидируете / перебито / выиграно).
6. **Профиль** (`ScreenProfile`) — аватар-инициал, телефон, кнопка «Выставить авто на торги», меню (`Выигранные лоты / Уведомления / Связь с менеджером / Личные данные`), «Выйти».
7. **Страницы профиля** (`ScreenProfilePage`): `personal` (личные данные + предупреждение о заполнении для участия), `notif` (уведомления с цветными точками статусов), `won` (выигранные лоты + договоры), `manager` (карточка менеджера + каналы связи: звонок, Telegram, WhatsApp, MAX, почта + «чем помогает»).
8. **Продать авто** (`ScreenSell`, `hifi-sell.jsx`) — форма заявки на выставление авто; состояние «отправлено».

### B. Веб-версия (`Автоаукцион - Веб.html`)
Корень `WebApp` (`hifi-web-lot.jsx`). Тёмная тема по умолчанию (Tweaks). Состояние «вошёл» — `localStorage` `cc_web_authed`.

- **Топбар** (`.topbar`, sticky, blur): бренд «HERMES», нав-ссылки, строка поиска (`.topsearch`, max 420px), аватар. На узких экранах нав-ссылки скрываются.
- **Аутентификация** (`WebAuth`, `hifi-web-auth.jsx`) — сплит-экран (форма + hero), вход через телефон/OTP, есть кнопка входа через Яндекс (`WebYaGlyph`). На узких экранах hero скрывается.

Корень `AdminApp`: сетка `236px 1fr` — сайдбар + основная область. Топбар с крошкой/заголовком и датой. Светлая, плотная, утилитарная.

## Поведение и взаимодействия

- **Реальное время:** таймеры лотов идут вниз (в прототипе `setInterval` 1 c). В продакшене обратный отсчёт, обновление макс. ставки, статуса резерва и ленты ставок — через WebSocket/SSE.
- **Срочность:** при `endsIn ≤ 300 c` лейбл «СКОРО КОНЕЦ», таймер краснеет (`--live`). Антиснайпинг (продление при ставке в последние секунды) — параметр в админке.
- **Ставки:** мин. следующая ставка = текущая + шаг. Степпер меняет на величину шага. Если ставку перебили — статус «перебито» (`.tag.out`), уведомление.
- **Резерв:** скрытая минимальная цена. Показывается «взят / не взят». Продажа только при взятом резерве; иначе «Резерв не взят» — можно перевыставить.
- **Авторизация / гейтинг:** неавторизованный → флоу входа. Для ставки нужны заполненные контакты (иначе → экран «Личные данные»).
- **Навигация:** мобайл — нижние табы + стек детальных экранов (кнопка назад). Веб — топбар + переключение вью. Админка — сайдбар + оверлеи форм поверх (топбар скрывается в режиме формы).
- **Состояния:** загрузка (таймеры/ленты), пусто («Ставок пока нет»), ошибка фото (фолбэк-плейсхолдер), отправлено (форма продажи/заявки).
- **Адаптивность веба:** сетка каталога 3→2→1; `.lot-grid` сворачивается на ≤980px; нав-ссылки скрываются ≤960px; hero авторизации скрывается ≤860px.

## Управление состоянием

Минимально необходимое:
- **auth:** `authed` (mobile `cc_authed`, web `cc_web_authed`), `contactsFilled` (`cc_contacts`). В продакшене — реальная сессия/токен.
- **navigation:** активный таб, стек детальных экранов / текущая вью / оверлей формы (админка).
- **catalog:** активный фильтр, поисковый запрос.
- **lot/live:** `now` (тик таймера), текущая ставка в инпуте, активный таб лота.
- **bids:** список ставок (real-time), лидирующая ставка, статус «перебито».
- **theme/tweaks (только прототип):** `theme` (dark/light), `accent`, `corners` — это демо-настройки внешнего вида (см. ниже), в продакшен можно не тащить.
- **data fetching:** список лотов, лот по id, лента ставок (стрим), профиль, уведомления, сделки, пользователи (админ), параметры аукциона.

## Модель данных (лот)

Из массива `LOTS` (`hifi-shared.jsx`). Поля лота:

```
id, make, family, model, year,
status,                 // live | ending | upcoming | sold | finished | withdrawn
fav, published, img, photos,
bid,                    // текущая макс. ставка (или стартовая для upcoming)
reserve, reserveMet,    // резерв и взят ли он
startsIn, endsIn,       // секунды до старта / конца (для отсчёта)
startLabel, endLabel,   // человекочитаемые метки времени
mileage, engine, power, fuel, transmission, drive, body, color,
bids,                   // число ставок
watchers,               // наблюдателей
desc,                   // описание
options: [],            // список опций
vin,
autoteka: {             // отчёт проверки истории
  attached, date, owners, accidents, restrictions,
  pledge, mileageOk, taxi, summary
}
```

Хелперы (`hifi-shared.jsx`): `fmt` (разделители тысяч `ru-RU`), `rub` (+ « ₽»), `fmtTime` (секунды → `чч ч мм м` или `мм:сс`), `fee` / `feePct` (комиссия 1.5%), `participantsOf`.

## Ассеты

- **Фото авто:** в прототипе — стоковые с Unsplash CDN через `photo(id, w)`. **В продакшене заменить на реальные фото лотов**; компонент `Photo` уже имеет фолбэк-плейсхолдер при ошибке загрузки.
- **Логотип/знак Hermes Trade:** рисуется кодом (SVG-компоненты `HermesH`, `HermesMark`, `HermesLogo` в `hifi-shared.jsx`; финальная версия — `Hermes Trade - Логотип финал.html`). Можно экспортировать в SVG-ассет.
- **Иконки:** инлайн-SVG набор `I` (см. выше). Заменить на icon-set кодовой базы при наличии.
- **Шрифты:** Google Fonts — `Hanken Grotesk`, `Space Grotesk`, `Marcellus`.
- Логотипы внешних брендов (Яндекс на экране входа веба) — использовать официальные ассеты этих брендов, не воссоздавать.

## Демо-настройки прототипа (Tweaks) — не для продакшена

Прототипы содержат панель Tweaks (`tweaks-panel.jsx`) для демонстрации вариантов оформления:
- **Тема:** dark / light.
- **Акцент:** `#c9533c` (терракота, основной), `#c08a2e`, `#3f6fc0`, `#2f9460`, `#7c5ad0`.
- **Углы:** soft (`16/12/8`) / sharp (`8/8/5`).

Канонический бренд — **тёрракота `#c9533c` + soft corners**. Остальное — исследование; реализуйте утверждённый вариант, темизацию (dark/light) оставьте если нужна продукту.
